# 图片生成 — PRD

## 1. 功能定位
TeraBox AI 美图模块，提供基于文字提示（文生图）和参考图片（图生图）的 AI 图像生成能力。面向需要快速生成营销图、头像、创意概念图、电商素材的内容创作者和普通用户。

## 2. 用户故事
- 作为 内容创作者，我希望 输入文字描述生成图片，以便 快速产出营销素材。
- 作为 电商运营，我希望 上传产品图 + 描述生成新场景图，以便 制作宣传图。
- 作为 普通用户，我希望 选择预设风格（油画/动漫/写实）转换我的照片，以便 制作个性头像。
- 作为 设计新手，我希望 通过预设模板一键转换图片风格，以便 无需设计技能。

## 3. 入口与导航
- URL: https://www.terabox.com/ai/photo-to-photo/chinese
- 进入方式: AI 主页 → 「图片生成」；或 AI 主页 tab 栏 → 「图片生成」
- 退出方式: 「后退」按钮 → `/ai/index/chinese`
- 顶部导航：与 Tera AI 共用相同 tab 栏

## 4. 页面元素（agent 视角）
| 元素 | role/name | 说明 |
|------|-----------|------|
| 模式单选：图片 | radio "图片" | 当前选中状态（checked） |
| 模式单选：视频 | radio "视频" | 切换到视频生成 tab |
| 子模式 chip：生成 | (chip) | 默认选中：纯生成模式 |
| 子模式 chip：特效 | (chip) | 切换到预设特效模板 |
| 主输入框 | textbox (multiline, focusable) "描述你想生成的画面最多可上传 9 张图片作为参考" | 接受文字 + 可选最多 9 张参考图 |
| 模型选择 | image+text "Nano Banana" | 当前模型 |
| 积分提示 | StaticText "本次消耗：5积分" | 单次生成消耗 |
| 生成按钮 | button "生成" | 触发生成 |
| 示例 prompt | StaticText | 4 个：酥皮火车 / 软糖游乐场 / 毛线艺术 / 水果分解 |
| 广场分类 tab | StaticText | Gallery / 26世界杯 / 探索 / 拼图专题 / 精选推荐 / 热门短视频 / AI 照相馆 |
| 用户头像墙 | image+StaticText | 多用户头像展示 |
| 后退按钮 | link "后退" | 返回主页 |

## 5. 输入与输出
| 项 | 描述 |
|----|------|
| 输入 | 文字 prompt（无明确上限）+ 可选最多 9 张参考图（JPG/PNG） |
| 输出 | 单张生成图片（PNG），展示在结果区，可下载 |
| 单次消耗 | 5 积分 |
| 模型 | Nano Banana（默认，可能支持切换） |

## 6. 业务规则
- **必须登录**才能点击「生成」
- **必须有足够积分**（至少 5 积分）
- 文字 prompt 不可为空
- 上传图片最多 9 张
- 生成的图片自动保存到用户 TeraBox 云盘
- 积分不足时按钮 disabled 或点击弹充值窗

## 7. 异常与边界
| 场景 | 期望表现 |
|------|---------|
| 输入为空 | 「生成」按钮 disabled |
| 未登录点击生成 | 引导登录 |
| 积分不足 | 提示「积分不足」+ 充值入口 |
| 网络失败 | 显示错误消息 + 重试按钮 |
| 上传非图片文件 | 拒绝上传 |
| prompt 超长 | 后端截断或报错 |
| prompt 含违规内容 | 拒绝生成 + 提示 |
| 生成超时（>60s） | 提示超时，可重试 |

## 8. 验收标准（Given-When-Then）
1. **Given** 用户访问 `/ai/photo-to-photo/chinese` **When** 页面加载完成 **Then** 主输入框、模型选择、生成按钮可见
2. **Given** 输入框为空 **When** 检查「生成」按钮 **Then** 按钮 disabled
3. **Given** 用户输入合法 prompt **When** 点击「生成」**Then** 「生成」按钮变为 loading 态，5 积分被扣除
4. **Given** 生成完成 **When** 检查结果区 **Then** 出现一张新生成的图片
5. **Given** 用户点击示例 prompt 之一（如「酥皮火车」）**When** 卡片被点击 **Then** 该 prompt 自动填入输入框
6. **Given** 用户切换子模式 chip 「特效」**When** chip 被点击 **Then** 输入框 placeholder/提示变化，提示切换到特效模式
7. **Given** 模式切换到「视频」**When** 视频 radio 被点击 **Then** 页面导航到 `/ai/photo-to-video/chinese`
8. **Given** 积分不足 **When** 点击「生成」**Then** 提示积分不足
9. **Given** 用户上传 10 张图片 **When** 上传 **Then** 第 10 张被拒绝（限制 9 张）
10. **Given** 用户点击「后退」**When** 按钮被点击 **Then** 回到 `/ai/index/chinese`

## 10. 自动化可行性
- **WEB_FUNCTIONAL**：登录态完整可用
- 未登录态：页面渲染 + UI 元素可访问测试
- 「生成」按钮的真实点击测试需要积分，建议作为集成测试阶段任务
