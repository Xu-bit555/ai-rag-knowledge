# 视频生成 — PRD

## 1. 功能定位
TeraBox AI 视频生成模块，基于文字提示或参考图片生成短视频（MP4）。面向需要快速制作短视频广告、社交媒体内容（TikTok / Instagram Reels）的电商运营和个人创作者。

## 2. 用户故事
- 作为 电商运营，我希望 上传产品图 + 简单脚本生成产品展示视频，以便 制作广告素材。
- 作为 社交媒体创作者，我希望 输入简短文字生成竖屏短视频，以便 快速发布。
- 作为 广告投放人员，我希望 批量生成多个广告变体视频，以便 A/B 测试投放。

## 3. 入口与导航
- URL: https://www.terabox.com/ai/photo-to-video/chinese
- 进入方式:
  - AI 主页 → 「视频生成」
  - AI 主页 tab 栏 → 「视频生成」
  - 图片生成页 → 模式切换到「视频」
- 退出方式: 「后退」按钮 → `/ai/index/chinese`

## 4. 页面元素（agent 视角）
| 元素 | role/name | 说明 |
|------|-----------|------|
| 模式单选：图片 | radio "图片" | 切换回图片生成 |
| 模式单选：视频 | radio "视频" | 当前选中 |
| 子模式 chip：生成 | (chip) | 文字+图片生成视频 |
| 主输入框 | textbox (multiline) | 输入脚本或上传图片作为参考 |
| 模型选择 | image+text | 当前模型（推断：与图片生成不同） |
| 积分提示 | StaticText | 单次视频生成的积分消耗（推断高于图片） |
| 生成按钮 | button "生成" | 触发视频生成 |
| 后退按钮 | link "后退" | 返回主页 |

## 5. 输入与输出
| 项 | 描述 |
|----|------|
| 输入 | 文字脚本（≤ 500 字推断）+ 可选 1-9 张参考图（JPG/PNG） |
| 输出 | MP4 短视频（竖屏 9:16 适合 TikTok / 16:9 适合其他平台），时长推断 5-15 秒 |
| 单次消耗 | 推断 20-50 积分（高于图片生成） |
| 生成时长 | 30 秒 - 3 分钟（视频生成比图片慢） |

## 6. 业务规则
- **必须登录**
- **必须有足够积分**（至少 20-50 积分）
- 文字脚本必填，参考图可选
- 最多 9 张参考图
- 生成的视频自动保存到 TeraBox 云盘
- 支持横屏/竖屏选择（推断）

## 7. 异常与边界
| 场景 | 期望表现 |
|------|---------|
| 输入为空 | 「生成」按钮 disabled |
| 未登录点击生成 | 引导登录 |
| 积分不足 | 提示充值 |
| 视频生成超时（>5 分钟） | 提示超时，可重试 |
| 服务端拒绝（如 NSFW） | 拒绝生成 + 提示 |
| 上传过多参考图 | 拒绝超出 9 张的部分 |

## 8. 验收标准（Given-When-Then）
1. **Given** 用户访问 `/ai/photo-to-video/chinese` **When** 页面加载完成 **Then** 主输入框、生成按钮、模型选择可见
2. **Given** 输入框为空 **When** 检查「生成」按钮 **Then** 按钮 disabled
3. **Given** 视频 radio 当前选中 **When** 检查「图片」radio **Then** 未选中
4. **Given** 用户输入合法脚本 **When** 点击「生成」**Then** 按钮变为 loading 态，积分被扣除
5. **Given** 视频生成完成 **When** 检查结果区 **Then** 出现新生成的视频播放器
6. **Given** 用户切换到「图片」**When** 切换被点击 **Then** 页面导航回 `/ai/photo-to-photo/chinese`
7. **Given** 积分不足 **When** 点击「生成」**Then** 提示积分不足
8. **Given** 用户点击「后退」**When** 按钮被点击 **Then** 回到 `/ai/index/chinese`
9. **Given** 视频生成超时 **When** 等待超过 5 分钟 **Then** 提示超时，可重试

## 9. 与图片生成的差异
- 输出：视频 vs 图片
- 输入：必需脚本 vs 可仅图片
- 消耗：更高积分
- 时长：更长生成时间

## 10. 自动化可行性
- **WEB_FUNCTIONAL**：登录态完整可用
- 视频生成实际执行耗时较长（30s+），测试用例需设置较长的 timeout
- 真实点击生成建议作为集成测试，单测仅覆盖 UI 状态
