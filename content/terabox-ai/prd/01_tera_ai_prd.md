# Tera AI — PRD

## 1. 功能定位
TeraBox AI 一站式对话助手（"Tera AI"），通过自然语言与多模态（文本 + 文件）交互，完成问答、总结、翻译、深度研究、影视搜索等任务。面向需要在线 AI 辅助的个人用户。

## 2. 用户故事
- 作为 创作者，我希望 快速生成文章、营销文案、邮件内容，以便 提高日常产出。
- 作为 学生/研究者，我希望 上传 PDF 让 AI 总结关键信息，以便 节省阅读时间。
- 作为 普通用户，我希望 通过对话查询电影观看渠道、事实信息，以便 获得附来源的答案。
- 作为 多任务办公者，我希望 在同一界面完成写作、翻译、PPT 生成、图片生成，以便 不必切换多个 AI 工具。

## 3. 入口与导航
- URL: https://www.terabox.com/ai/agent
- 进入方式: AI 主页 tab 栏 → 点击「Tera AI」
- 退出方式: 点击「后退」按钮回到 `/ai/index/chinese`
- 顶部导航：Tera AI / AI 笔记本 / 标准PPT生成 / 智能PPT助手 / 美化幻灯片 / 图片生成 / 视频生成 / AI听记 / Nano Banana 幻灯片

## 4. 页面元素（agent 视角）
| 元素 | role/name | 说明 |
|------|-----------|------|
| 主输入框 | textbox (multiline) "搜索、创建或完成事项" | 用户输入 prompt，支持多行 |
| 上传图标 | image "upload icon" | 文件上传入口 |
| 主操作按钮 | button "继续" | 输入为空时 disabled |
| 示例 prompt 卡片 | image + StaticText | 4 个示例：搜索猫和老鼠 / 小学生自我保护 / Ozempic 效应 / AI写真公司邮件营销 |
| 换一批按钮 | (button) | 刷新示例 prompt |
| 后退按钮 | link "后退" | 返回 AI 主页 |
| 登录链接 | link "登录" | 未登录时显示在右上 |

## 5. 输入与输出
| 项 | 描述 |
|----|------|
| 输入 | 文本（无明确长度上限）；可选上传文件（DOCX / PDF / TXT / XLSX / PPTX / JPG / JPEG / PNG，最多 10 个文件） |
| 输出 | 流式 AI 回复文本；可生成可下载的结果（演示文稿、图片、视频、文档） |
| 输出格式 | 文本（流式）、PPTX、DOCX、PNG、MP4 |

## 6. 业务规则
- **必须登录**才能发送对话（未登录点击「继续」会引导到登录页）
- 提示词可中英文混合
- 上传文件大小和数量受限（最多 10 个）
- 部分高级功能（如深度研究、文档分析）需登录态
- 输出结果自动保存到用户 TeraBox 云盘

## 7. 异常与边界
| 场景 | 期望表现 |
|------|---------|
| 输入为空 | 「继续」按钮 disabled |
| 仅空白字符 | 「继续」按钮 disabled |
| 超长输入 | 后端截断（具体阈值未知） |
| 网络失败 | 错误提示 + 重试按钮 |
| 未登录发送 | 引导登录（弹窗或跳转） |
| 服务端拒绝 | 显示错误码 + 建议 |
| 上传非法格式 | 拒绝上传 |

## 8. 验收标准（Given-When-Then）
1. **Given** 用户未登录 **When** 访问 `/ai/agent` **Then** 页面正常渲染，输入框可见，但点击「继续」跳转登录页
2. **Given** 用户输入合法 prompt **When** 点击「继续」**Then** 在合理时间内（≤ 30s）开始流式输出 AI 回复
3. **Given** 输入框为空 **When** 检查「继续」按钮状态 **Then** 按钮 disabled
4. **Given** 用户点击示例 prompt 卡片 **When** 卡片被点击 **Then** 该 prompt 自动填入输入框
5. **Given** 用户点击「换一批」**When** 按钮被点击 **Then** 4 个示例 prompt 刷新为新一组
6. **Given** 用户点击「后退」**When** 按钮被点击 **Then** 导航回 `/ai/index/chinese`
7. **Given** 用户上传 PDF 文件 **When** 上传完成 **Then** 文件缩略图出现在输入框附近
8. **Given** AI 回复进行中 **When** 检查页面 **Then** 看到流式文本增量出现
9. **Given** AI 生成结果（如 PPT）**When** 生成完成 **Then** 可下载并保存到 TeraBox 云盘
10. **Given** 网络中断 **When** 正在生成 **Then** 显示错误提示，可重试

## 9. 能力清单（agent 视角）
| 能力 | 入口 | 说明 |
|------|------|------|
| AI 对话 | 主输入框 | 任何问题直接对话 |
| AI 总结 | 主输入框 + 文件 | 上传 PDF/文档后请求总结 |
| AI 翻译 | 主输入框 | 提交翻译请求 |
| 深度研究 | 主输入框 | 长文本研究报告 + 来源标注 |
| 影视搜索 | 主输入框 | 查询电影观看渠道 |
| 云端整合 | 自动 | 结果保存到 TeraBox |

## 10. 自动化可行性
- **WEB_FUNCTIONAL**：在登录态下完整可用
- **未登录态**：仅页面渲染测试，自动化 agent 需要先完成登录（建议作为前置 setup 步骤，不在单个 case 内）
